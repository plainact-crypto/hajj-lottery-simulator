## Editorial rules
1. Evergreen pages explain stable concepts and practical preparation.
2. Seasonal rules, health requirements, permits, visa eligibility and operating procedures must be verified from the current official source.
3. Religious pages do not issue personalized fatwas or resolve madhhab differences.
4. Official Saudi awareness guides are used as a verification layer for Hajj/Umrah operational guidance.
5. Egypt-specific commercial or regulatory claims should point to current Egyptian official sources when material to a decision.
6. Each page has a distinct search intent to reduce cannibalization.

## Internal linking model
Pillar -> supporting guide -> relevant interactive tool -> official source.

This keeps the site useful even outside the seasonal Hajj application window and supports year-round organic search demand.
